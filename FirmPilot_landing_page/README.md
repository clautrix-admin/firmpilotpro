# FirmPilot Landing Page

Minimal public holding page for `firmpilotpro.dev`.

Purpose:
- keep the root domain live
- avoid exposing product details before launch
- provide a clean brand presence and contact email

Files:
- `index.html`
- `styles.css`

Usage:
- deploy this folder as a static site
- point the root domain `firmpilotpro.dev` to it

Current content policy:
- no feature list
- no pricing
- no product workflow details
- no app screenshots
- no internal portal links
